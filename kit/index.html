Stop shipping an AI agent you have never attacked.

Prompt injection is the number-one security risk for LLM-powered applications: a crafted piece of text — in a user message, a fetched web page, an email, a PDF, a code comment, or a tool result — quietly hijacks your agent and makes it ignore its instructions, leak secrets, call the wrong tool, or take an irreversible action on someone else's behalf. Unlike a classic injection bug, there is no single line to patch. The only way to know whether your agent holds up is to attack it the way a real adversary would, repeatedly, and measure the result.

This kit gives you that in an afternoon instead of a week.

What's inside

  • A curated corpus of 40+ prompt-injection attack cases (cases/injection-cases.json), spanning eight distinct attack families: direct instruction override, role-play and DAN-style jailbreaks, data exfiltration through tool calls, indirect injection hidden inside fetched documents, encoding and obfuscation tricks, authority impersonation, multi-turn setup attacks, and slow policy erosion. Every case is hand-written, varied, and labelled with the safe action a hardened agent should take (refuse, ignore_embedded_instruction, ask_operator, or comply_safely). No templated filler.
  • A scoring runner (runner.py) that replays the whole corpus against a target and prints a single SCORE: passed/total. It ships with two deterministic mock agents — a hardened one and a naive one — so you can see the harness discriminate between a defended and an undefended agent before you ever point it at your own.
  • A --target http mode that runs the same corpus against your real agent over a simple JSON endpoint, so this becomes a regression gate in your CI.
  • A hardening checklist (checklist.md) of concrete defenses — from instruction/data separation to tool allow-lists and human-in-the-loop gates.
  • A report template (report-template.md) you can drop findings into and hand to a client, a manager, or an auditor.

Who it's for

Engineers and security reviewers building agents, chatbots, RAG pipelines, or any LLM feature that reads untrusted text or calls tools.
